# Upstream provenance

DeepSeek Work currently launches, but does not copy, a separate DeepSeek Harness checkout.

- Source: <https://github.com/deepseek-ai/deepseek-harness>
- Verified development version: `0.1.0-rc.5`
- Upstream package: `@deepseek-ai/dsh-root`
- License: MIT, copyright (c) 2026 DeepSeek

Before Harness source or built artifacts are included in a DeepSeek Work distribution, the packaging process must pin an exact upstream revision and include the upstream copyright and MIT permission notice in the distributed third-party notices.
